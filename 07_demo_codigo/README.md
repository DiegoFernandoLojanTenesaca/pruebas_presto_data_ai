# 07 - Demo Rapida para Compartir Pantalla

Script limpio y minimo para mostrar en la entrevista si piden ver codigo o una demo en vivo.

## Que hace
- Agente funcional con 2 herramientas (buscar info + agendar)
- Chat interactivo: escribe como lead y ve la respuesta
- Comando 'demo' para ejemplo automatico rapido
- Codigo limpio y comentado, facil de explicar

## Ejecutar
```bash
cd presto-pruebas
venv/bin/python 07_demo_codigo/main.py
```

## Tip
Este es el script mas simple. Si te piden mostrar algo rapido, usa este.
Si quieren ver algo mas completo, usa `05_caso_lead/main.py`.
